# 💰 Fynanz

### A Smart Expense Tracker Web Application

Fynanz is a web application designed to help users **track, manage, and analyze their expenses** efficiently.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, FastAPI
- **Database:** MongoDB, MySQL

## 🎯 Objective

To provide a simple and organized platform for **expense management and financial tracking**.
